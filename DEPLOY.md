# Выкладка сайта САПС на VPS (Beget)

## Первая установка

1. В панели Beget создайте VPS с **Ubuntu 22.04 или 24.04**. Серверы Beget в России — это требование закона о персональных данных.
2. Подключитесь к серверу по SSH от root и выполните одну команду
   (до слияния ветки в `main` укажите ветку явно):

   ```bash
   curl -fsSL https://raw.githubusercontent.com/moooooooooos/sups/feature/color-album/run.sh | BRANCH=feature/color-album bash
   ```

3. Скрипт спросит:
   - **домен** без www (например, `sups-official.ru`);
   - **логин и пароль администратора** (пароль не короче 10 символов);
   - **email для SSL-сертификата**. Если DNS ещё смотрит на Тильду, оставьте пустым: сертификат выпустится при следующем запуске, после переключения домена.
4. Перед запуском сайта скрипт сам прогоняет проверку (`npm run smoke`). Если она не прошла, сайт не перезапускается.

## Переключение домена с Тильды

1. Откройте сайт по IP сервера, войдите в админку и заполните «Настройки»: ЮKassa, СДЭК (ключи и код офиса отправки), почта для писем покупателям, Telegram-бот.
2. В DNS домена смените A-записи `@` и `www` на IP сервера.
3. Через 10–30 минут ещё раз запустите на сервере `bash /var/www/sups-store/deploy.sh` — выпустится SSL.
4. Тильду **не отключайте**, пока все фото товаров не перезалиты в админку: сейчас большинство из них хранится на серверах Тильды.
5. В Яндекс Вебмастере и Google Search Console добавьте `https://ваш-домен/sitemap.xml`. Старые адреса товаров с Тильды продолжают работать.

## Обновление сайта

```bash
BRANCH=feature/color-album bash /var/www/sups-store/run.sh
```

Код обновится, а база заказов, фото и настройки останутся на месте. Перед обновлением база копируется в `/var/backups/sups/`.

## Полезное

| Что | Команда |
|---|---|
| Сменить пароль админа | `cd /var/www/sups-store && npm run admin-password` |
| Логи сайта | `pm2 logs sups-store` |
| Перезапуск | `pm2 reload sups-store` |
| Бэкапы базы | `/var/backups/sups/` (каждый день в 04:30, хранятся 14 копий) |
| Восстановить базу | `pm2 stop sups-store && gunzip -c /var/backups/sups/sups-ДАТА.db.gz > /var/www/sups-store/data/sups.db && pm2 start sups-store` |

База (`data/sups.db`), секреты (`data/.secrets.json`) и настройки домена (`data/.deploy.json`) хранятся только на сервере, в git их нет.
