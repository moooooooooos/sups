🚚 Доставка

Цены и пункты выдачи берутся из API перевозчиков. Покупатель выбирает город и пункт выдачи из списка, адрес для курьера проверяется. Пока ни один перевозчик не подключён, адрес вводится вручную, а цена берётся из поля ниже.

СДЭК

Боевые ключи: личный кабинет СДЭК → «Интеграция» → «Создать ключ». Тестовые данные опубликованы на apidoc.cdek.ru. Справочник городов СДЭК используется и для Яндекс Доставки, поэтому СДЭК нужно подключить в любом случае.

Яндекс Доставка
Подсказки адреса до дома (DaData, необязательно)

С ключом DaData покупатель выбирает улицу и дом из подсказок, поэтому несуществующий адрес для курьера указать нельзя. Без ключа проверяется только формат улицы и номера дома. Ключ бесплатный: dadata.ru → «API-ключи».
